# Inkframe free brush sets

Brush sets shared by their authors under open licenses, converted to Inkframe's `.inkbrushset` format
for one-tap download inside the app. Each set keeps its original license and credit.

- Converted files are adaptations of the originals and are distributed under the same license as each original set.
- GPL sets include their original source files under `sources/`. MIT / Apache notices are in `licenses/`.
- David Revoy's sets: "This attribution is necessary in case of redistributing the pack, commercializing it, or modifying the brushes files" — credit: **David Revoy, www.davidrevoy.com**.
